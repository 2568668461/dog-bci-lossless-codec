# 犬类神经数据集调研报告

> 调研目标：寻找**犬类（dog/canine）、同时包含 LFP 与 spike、最好为 Intan 格式**的公开神经数据集，用于犬类嗅觉 BCI 压缩方案的数据支撑。
> 调研日期：2026-09-07
> 检索渠道：DANDI、OpenNeuro、G-Node GIN、Zenodo、HuggingFace、iEEG Portal / Kaggle、Web 文献检索（OpenAlex/期刊）

---

## 一、核心结论（先说答案）

**公开渠道不存在"犬类 + LFP + spike"的颅内神经数据集，Intan 格式的更没有。**

犬类颅内电生理公开数据只有一类：**癫痫犬 iEEG**（Mayo/UPenn，400 Hz 采样、皮层条状电极）。400 Hz 无法记录 spike（spike 需要 ≥10 kHz），所以全世界公开的犬类数据本质上都是"LFP 频段"数据。含单单元的犬类记录只存在于零星文献（多为上世纪 60–90 年代急性/半慢性实验）和商业公司私有数据中，无一公开。

这本身就是一个有价值的调研结论：**犬类嗅球/梨状皮层的 spike 级公开数据是整个领域的空白**——Canaery（General Sense）这类公司正垄断这部分数据。对我们而言，压缩算法验证只能继续用啮齿类数据，并在报告中明确"跨物种迁移"的假设。

## 二、犬类公开数据全景

### 2.1 唯一的犬类颅内数据集：Canine Epilepsy Dataset

| 项 | 内容 |
|---|---|
| 名称 | Canine Epilepsy Dataset（UPenn / Mayo / NeuroVista） |
| DOI | 10.26275/ju7v-hnyy（也经 IEEG Portal、Kaggle Seizure Prediction Challenge 分发） |
| 动物 | 3 只自然发生局灶性癫痫犬（另有 Kaggle 版本 5 只：L2/L7/M3/P1/P2） |
| 电极 | 双侧 4 触点硬膜下条状电极 ×4 = 16 通道 |
| 采样率 | **400 Hz**（无线植入系统 NeuroVista） |
| 时长 | 45.8 / 451.9 / 475.7 天（连续），共 263.6 GB |
| 内容 | iEEG（≈LFP）+ 专家标注发作时刻 + 发作间期爆发 |
| 格式 | EDF / iEEG Portal 专有 / Kaggle CSV-clips，**非 Intan、无 spike** |
| 许可 | CC0 |

**适用性**：✅ 犬类皮层 LFP（含发作期高幅瞬态）压缩测试；❌ spike 压缩；❌ 嗅觉相关（电极在皮层，非嗅脑）。

## 三、最优替代方案：啮齿类嗅球 spike+LFP 数据

既然犬类数据是空白，压缩管线验证建议用**同脑区（嗅球）、同任务（气味+嗅吸）、有 spike+LFP** 的啮齿类数据：

### 3.1 首选：DANDI 001539 — 大鼠气味-空间关联任务

| 项 | 内容 |
|---|---|
| 名称 | Odor-Place Spatial Association Task（Symanski 等） |
| 内容 | **嗅球 + 海马 + 前额叶**多区同步记录 |
| 信号 | **单单元 spike + LFP** + 位置/速度 + 鼻戳/奖赏 trial 信息（气味任务） |
| 规模 | 38 个 NWB 文件（每文件一次 session，2–5 GB，共约 100 GB+） |
| 许可 | CC-BY-4.0 |
| 获取 | `dandi download DANDI:001539/draft` |

**为什么合适**：同时有 spike 和 LFP（正好做我们近无损方案的"spike 保真评测"）；气味诱发范式（与犬类嗅觉 BCI 同构）；清醒自由行为（不像 Rat06 是麻醉态）；多脑区（可对比嗅球 vs 皮层的可压缩性差异）。

### 3.2 备选

| 数据集 | 内容 | 备注 |
|---|---|---|
| DANDI 001252（Sterrett 2024） | 小鼠嗅球自由行为 + 呼吸记录 + 电生理 | 最贴近"嗅吸节律调制嗅球活动"，但 **draft 版 assets=0，数据尚未上传**，暂不可用 |
| Horváth 2021（现用 rat128） | 麻醉大鼠新皮层 128ch | 已在用；缺点：麻醉态、非嗅脑、仅 3 个自带单元 |
| Allen Institute Neuropixels（如 DANDI 000409 等） | 小鼠全脑 spike+LFP，含气味任务版本 | 高密度（>384ch）、清醒、含视觉/气味刺激，适合"高通道数压缩"压力测试 |

### 3.3 关于 Intan 格式

公开数据几乎都转成了 **NWB（HDF5）**，原始 Intan 格式（.rhd/.rec）一般不随数据集发布（Horváth 2021 也一样）。但这不影响压缩测试——我们已有 NWB→int16 的提取管线（rat_test.py），NWB 内就是原始 ADC 码值，与 Intan 导出等价。若必须验证 Intan 容器本身，可参考公开的 Intan 采样数据（Intan 官网 demo 文件）或用 SpikeInterface 的 intan 读取器处理任何 .rhd 数据。

## 四、建议

1. **压缩算法主线**：继续用 rat128（已完成全套基准）+ 新增 DANDI 001539（清醒态、嗅球、气味任务）作为第二个基准——两者一个麻醉/皮层、一个清醒/嗅球，正好覆盖两个极端，让 drice/JPEG-LS 结论更硬。
2. **犬类论证**：组会/报告中可明确写"犬类颅内 spike 数据全球无公开数据集（已系统检索 DANDI/OpenNeuro/G-Node/Zenodo/HF/文献）"，这反而支撑自建采集系统的必要性论证，也解释了为何用啮齿类数据做算法验证。
3. **竞品情报**：Canaery/General Sense（与 LLNL 合作）已在做"嗅球表面 ECoG 128 通道 + AI 解码"的犬类鼻-机接口（WIRED 2025-02 独家报道），建议在立项文档中列为对标对象。
4. **如果只要犬类 LFP**：Canine Epilepsy Dataset（CC0，263 GB）可用来测犬类皮层 LFP 的压缩率，但注意它是 400 Hz 采样、16 通道、硬膜下宏电极——信号统计特性（幅度/噪声）与 30 kHz Intan 微电极完全不同，结论只能作参考。
